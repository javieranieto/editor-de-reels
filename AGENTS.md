# AGENTS.md — el editor de reels, si trabajas con Codex

La fuente es [`CLAUDE.md`](CLAUDE.md) de esta misma carpeta: **léelo completo al empezar y
síguelo**; todo lo que dice "Claude" aplica a ti. Las guías de `.claude/skills/` (revisar-reel,
video-animado, destilar-herramienta) se **leen y se siguen** cuando el usuario pide lo que
describen: Codex no las carga solo.

Requisito que no cambia: **Windows con CapCut de escritorio y ffmpeg.** La versión gratis de
CapCut abre los proyectos; los efectos marcados como Pro se avisan por nombre.
